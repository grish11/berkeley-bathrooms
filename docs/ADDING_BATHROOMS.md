# Adding bathrooms

Step-by-step walkthrough for adding a building, a bathroom, photos, ratings,
and hours by editing the JSON files in `data/`.

**Not written yet — this lands in Phase 2**, once the JSON files and their
schema exist.

It will cover:

1. Adding a building to `data/buildings.json` (including finding its lat/lng)
2. Writing a weekly `access_schedule`
3. Adding a bathroom to `data/bathrooms.json`
4. Shooting photos — **no people, ever** — and running the Phase 8 compression
   script to strip EXIF and resize them
5. Filling in all nine category ratings
6. Checking your work locally before committing

See [DATA_FORMAT.md](DATA_FORMAT.md) for the field-by-field reference.
